# TempoTec V1 Arcade 1.4.4.3

Development preview of Pocket Arcade integrated with Sonix Player
for the TempoTec Variations V1 digital audio player.

## Highlights

- 12-game Pocket Arcade collection
- Pocket Dungeon: Relics of the Lantern
- Custom Arcade artwork and interface integration
- Arcade audio integration with Sonix Player
- Updated multilingual interface strings
- Qobuz integration retained from Sonix Player
- Stock TempoTec V1 kernel preserved

## Hardware validation

The private 1.4.4.3 development firmware has been successfully
installed and booted on a physical TempoTec Variations V1.

Its firmware package passed kernel integrity, filesystem chunk,
device identity, and CA certificate validation.

Successful boot does not establish that every game, audio feature,
or streaming function has passed hardware testing.

## Building

Follow the repository's existing Sonix Player build instructions
and V1 firmware packaging workflow.

Use a legitimate stock TempoTec V1 firmware image as the packaging
base. Review all device compatibility and recovery warnings before
installing custom firmware.

## Qobuz credentials

No private Qobuz application credentials, encryption keys, or
credential-bearing firmware images are included in this release.

Users are responsible for supplying any credentials required by
the relevant streaming services.

## Release status

Development preview, not a finished production release.
Additional gameplay testing, performance optimization, and
regression testing remain in progress.

This project is unofficial and is not endorsed by TempoTec.
